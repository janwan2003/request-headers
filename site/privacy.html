Privacy policy

Last updated: 2026-11-20. Applies to the HeaderDial browser extension and this website.

Short version

HeaderDial collects nothing. It has no analytics, no account, no server, and the extension makes no network requests of its own.

What the extension stores

Your profiles (header names, values, filters, colours) and a status note about which rules are applied are kept in the browser's local extension storage on your computer. They never leave it unless you export a file or create a share link yourself.

What the permissions are for

PermissionWhy
declarativeNetRequestHands the browser the header rules from your profiles. The browser applies them; HeaderDial does not see the requests or their content.
Site access (optional)Browsers only let an extension change headers on sites it has access to. You grant it from the popup, for all sites or only the current one, and can revoke it in the browser's extension settings.
storageSaves your profiles locally.
alarmsSwitches timed headers off when their time is up.
activeTabWhen you open the popup, lets it read the current tab's address so it can offer "Only on this site" and show how many requests in the tab were changed.

Share links

A share link contains the profile itself, encoded after the #. Browsers do not send that part of a link to the web server, so opening the link on this website does not transmit the profile. Anyone you give the link to can read it, so leave out tokens and passwords (the share dialog has an option for that).

This website

This site is hosted on GitHub Pages. It has no analytics or cookies of its own. GitHub may keep standard server logs, as described in GitHub's privacy statement.
