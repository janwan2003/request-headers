ModHeader alternative: import your ModHeader profiles

If you used ModHeader and need a replacement, HeaderDial can read a ModHeader profile export directly. Open HeaderDial, click Import…, and paste the JSON or choose the .json file. Profile names, colours, request and response headers, request and response cookies, URL replacements, URL filters and resource types carry over. Anything that can't be converted is listed in a warning, so nothing is dropped silently.

What happened

ModHeader was removed from Microsoft Edge Add-ons on 2026-07-03 and from the Chrome Web Store on 2026-07-10, after a dormant data collector was found in the extension. See The Hacker News report for details. If you still have it installed, read that report and decide whether to remove it. A header editor sees every request it is allowed to modify, so it deserves more scrutiny than most extensions.

Steps

  1. Find your export. ModHeader's popup let you export profiles as JSON. Look for a .json file you saved earlier, or JSON text you shared with a colleague. HeaderDial accepts a single profile, a list of profiles, or an object with a profiles list.
  2. Install HeaderDial and click its toolbar icon. You can click ⤢ to open the editor in a full tab, which gives more room when reviewing imported profiles.
  3. Click Import… in the footer. Paste the JSON, or choose the file.
  4. Decide whether to tick Replace existing profiles. Leave it unticked to add the imported profiles next to the ones you have.
  5. Click Import and read the summary. Any warnings name the profile and the part that was skipped.
  6. When the site-access banner appears, choose Allow on all sites or Only <current host>. Without site access the browser does not let any extension change headers.
  7. Check each profile's headers and its Where it applies section, then reload a page you use it on.

Imported profiles start out active. Use each profile's Active switch to turn off the ones you don't need straight away.

What is not imported

These have no equivalent yet. The import warning lists each one it found:

  • Tab, tab-group, window and time filters. For a per-tab profile, tick Only in this tab (until it closes); for time limits, use the expiry select on each header row (15 min to 1 day).

Things to check after importing

  • Regex syntax. URL regex filters use RE2 syntax, which has no lookbehind. A filter the browser rejects is reported as a problem in the popup, and the rest of the profile keeps working.
  • Append on request headers. Browsers only allow appending to a fixed set of request headers (such as Accept, Accept-Language, Cookie, User-Agent, X-Forwarded-For). For others, HeaderDial sets the value instead and says so.
  • Priority. When two active profiles set the same header, the leftmost chip wins. Reorder with Move left (higher priority) in the ⋯ menu.
  • Keep a backup. Export all saves everything to headerdial-profiles.json.

How to tell whether a header extension is trustworthy

Whatever you install next, these checks take a few minutes:

  • Open source, and the store build matches it. You or anyone else can read what the code does. Look for a public repository with recent, readable history.
  • No remote code. Manifest V3 forbids loading remotely hosted code, but an extension can still fetch configuration and data. Check whether it makes network requests at all, and to where. Look at the background service worker in the DevTools Network panel, reached from the extension's "Inspect views" link on chrome://extensions.
  • Minimal permissions. A header editor needs declarativeNetRequest and access to the sites it modifies. Be wary of tabs, history, cookies, scripting or content scripts on all pages without a clear reason. Read the permission list on the extension's details page.
  • Site access you control. On chrome://extensions, open Details and set site access to specific sites or "On click" where possible.
  • No account, no analytics. A local tool has no reason to need a login or to report usage.
  • Watch ownership changes. Popular extensions are sometimes sold, and a new owner can ship a different update. A change of publisher or a sudden new permission is a reason to look again.

For reference, HeaderDial's permissions are declarativeNetRequest, storage, alarms and activeTab, plus optional site access you grant from the popup. It has no account and no analytics, and the extension makes no network requests. The source is on GitHub, so you can check all of this yourself.
