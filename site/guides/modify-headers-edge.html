How to modify HTTP headers in Microsoft Edge

Microsoft Edge has no setting for adding or changing arbitrary headers on the requests a site makes. Its DevTools can override a few things for one tab, but for anything lasting you need an extension. HeaderDial is not on Edge Add-ons yet, so install it from the release zip: download headerdial.zip, open edge://extensions, turn on Developer mode, click Load unpacked and choose the unzipped folder. Edge is built on Chromium, so it runs the same build as Chrome.

Install from the release zip

  1. Download headerdial.zip (version 0.2.0) and unzip it into a folder you will keep. Edge loads the extension from that folder each time it starts, so don't unzip it into Downloads and then clean up.
  2. Open edge://extensions, or Settings and more › Extensions › Manage extensions.
  3. Turn on the Developer mode toggle.
  4. Click Load unpacked and select the folder that contains manifest.json.
  5. Click the Extensions button next to the address bar and pin HeaderDial so its icon and badge stay visible.

A loaded folder does not update itself. When a new release comes out, unzip it over the same folder and click Reload on HeaderDial's card in edge://extensions. Your profiles are kept, because they are stored by the browser, not in the folder.

A note on honesty: we test every release in Chrome and Firefox, not in Edge itself. The behaviour described in our other guides was measured in Chrome 159, which shares Edge's engine.

Steps

  1. Click the HeaderDial icon. The banner says "HeaderDial needs your permission before it can change headers on websites". Choose Allow on all sites, or Only <current host> for just the site you are on. If a page calls an API on another host, allow both.
  2. Click + Request header and enter a name and value, for example Authorization and Bearer eyJ…. Pick set, append or remove. Use + Response header to change what servers send back.
  3. Open Where it applies, click + Only on…, choose Domain and enter your host. You can also tick request types, or methods under Methods (none ticked = all), for example only POST.
  4. Reload the page and check the request in the DevTools Network panel or in your server log.

Everything else works as in Chrome: several profiles with their own Active switch, an expiry per row from 15 min to 1 day, Only in this tab (until it closes), and Import… / Export all. To move a setup between browsers, export it in one and import the file in the other.

Pause shortcut and private windows

Alt+Shift+D pauses or resumes every profile; the badge shows "off" while paused. Alt+Shift+H opens the popup. If either key clashes with something else, change it on edge://extensions/shortcuts.

Extensions don't run in InPrivate windows by default. To change headers there, open HeaderDial's Details in edge://extensions and turn on Allow in InPrivate.

Coming from an extension that was removed

A well-known header extension was removed from Microsoft Edge Add-ons on 3 July 2026, and from the Chrome Web Store a week later. If you exported its profiles as JSON, HeaderDial can import them: click Import… and paste the JSON or choose the file. Headers, response headers, URL filters and resource types carry over, and anything that can't be converted is listed in a warning. Switching header extensions has the details, the report about the removal, and a checklist for judging any header extension.

What Edge DevTools can do without an extension

Edge's DevTools cover some cases. Microsoft describes each of these in its Network features reference:

  • Change the User-Agent. In the Network conditions tool, clear Use browser default and pick or type a user agent. Device emulation sets one too.
  • Block requests. The Network request blocking tool (under More tools) blocks URLs matching a pattern, to see how a page copes without a script or API.
  • Override response headers with local overrides, for files you choose.
  • Edit and resend as fetch, a right-click command in the Network panel that copies a request into the Console as a fetch() call you can edit and run.
  • Disable cache, a checkbox at the top of the Network panel.

These apply to the tab DevTools is attached to, while DevTools is open. None of them adds a header such as Authorization to every request a page makes, removes a request header, or switches itself off on a timer.

The curl equivalent

curl -H "Authorization: Bearer eyJ…" https://staging.example.com/api/me

In the Network panel, right-click a request and use one of the Copy as cURL entries under Copy to get the full command with every header Edge sent.
