ModHeader alternatives compared (2026)

ModHeader was removed from Edge Add-ons on 3 July 2026 and from the Chrome Web Store on 10 July 2026, after researchers found a switched-off browsing-history collector in it (what was found). This page compares the tools people actually move to. Every user count, rating, price and update date below was checked 2026-11-20 on the store listing or the vendor's own page. Sources are listed at the end.

This page is written by the people who make HeaderDial, one of the tools compared. We have tried to say plainly where the others are better. If something here is wrong or out of date, open an issue and we will fix it.

The short answer

  • You want more than headers (mock API responses, an API client, team sharing): Requestly, or Tweak if you want cheap paid tiers and no account.
  • You want a free, open-source header and redirect tool that is in every store today: Header Editor (on Chrome it is called Header Editor Lite).
  • You only need to change one response header for a few minutes: Chrome DevTools can do it with nothing to install.
  • You want a small header editor with no account, no analytics and no network requests, and a way to get your ModHeader profiles back even without an export: HeaderDial. It is not in the Chrome Web Store or on Firefox Add-ons yet (details below).

Features at a glance

A request header is sent by the browser to the server (for example Authorization). A response header comes back from the server (for example Access-Control-Allow-Origin). A redirect rule sends a request to a different URL, for example from production to localhost. "ModHeader import" means the tool reads the JSON file that ModHeader's export button produced.

Each tool in short

HeaderDial

Best for: people who want a header editor and nothing else, with no account, no analytics and no network requests from the extension, and who want their ModHeader profiles back.

  • Headers and redirects: sets, appends or removes request and response headers, adds cookies, and redirects URLs. Filters by domain, URL pattern, regular expression, request type, request method, the page that made the request, or one tab. Headers can expire on a timer, from 15 minutes to 1 day.
  • From ModHeader: imports ModHeader's export file. If you never exported, the recovery page reads the profiles from ModHeader's data folder in your browser profile. As far as we know, no other tool on this page offers that.
  • Permissions: declarativeNetRequest (the browser's built-in rule engine for changing requests, so the extension's code never sees your traffic), storage, alarms and activeTab. Access to sites is optional and granted from the popup.
  • Where it is weaker: it is new. It has no store listing yet, so no ratings and no track record. It cannot mock responses, change response bodies, sync between computers or share rules with a team. There is no Safari version.
  • Install: coming soon. The Chrome Web Store listing (which Edge can install from too) is waiting to be published. On Firefox it was submitted to Firefox Add-ons on 2026-11-20 and becomes installable there once Mozilla's review is done.

Requestly

Best for: teams who want headers plus much more: mock API responses, change request and response bodies, inject scripts, record and share sessions, and an API client (a tool for sending and testing API requests, like Postman).

  • The largest alternative by users in the Chrome Web Store. Requestly says it is now part of BrowserStack.
  • Imports ModHeader profiles as rules, and documents the steps.
  • Has team workspaces, rule sharing, single sign-on and audit logs for companies. HeaderDial has none of these.
  • Available for Chrome, Edge, Firefox (as a download from Requestly's site) and Safari, plus a desktop app.
  • Price: its ModHeader comparison page lists a free plan with unlimited header rules and a custom-priced Enterprise plan. Its main pricing page lists the API platform at $10 (Team) or $15 (Team Pro) per user per month, billed annually.

Header Editor and Header Editor Lite

Best for: a free, open-source rules tool for headers and redirects that is already in every store, with a long history.

  • Changes request headers, response headers and URLs, and can cancel requests.
  • Two editions from the same team. Header Editor Lite uses Manifest V3 (the current extension format that Chrome requires) and is the one in the Chrome Web Store. The full Header Editor adds custom JavaScript functions and response-body changes. The project recommends Lite unless you need those.
  • Large on Edge: 630,066 active installs.
  • No account needed. Its source shows optional backup of your rules to a cloud drive (OneDrive, Google Drive, Yandex Disk).
  • For ModHeader, the team offers a separate converter page that takes a ModHeader.json file. We have not tested it with a current ModHeader export.

Simple Modify Headers

Best for: a plain rules table for request and response headers on Firefox, from a long-standing open-source project.

  • Adds, changes or removes request and response headers and cookies, with URL patterns.
  • The last update was in mid-2024 on both stores. The author's README explains that the Chrome version has limits that the Firefox version does not, because of Manifest V3.
  • Its README lists import of its own export files and of the "Modifyheaders" format, not ModHeader files.

Modify Header Value

Best for: adding, changing or removing a request header on chosen sites, with a simple on/off switch.

  • Its vendor describes it as changing request headers only.
  • Its vendor page links to listings for Chrome, Firefox, Edge and Opera.

Tweak

Best for: front-end developers who want to mock API responses and edit headers, with cheap paid plans.

  • Free plan: header rules, redirects, and up to 12 mock rules, with no account. Paid plans add unlimited rules, changes to real responses, breakpoints, variables and environments.
  • Its FAQ says rules stay in the browser and that basic usage analytics are collected. Its Firefox listing licence is "all rights reserved", so it is not open source.
  • In all three stores.

FlexHeader

Best for: an open-source header editor that also imports ModHeader files and syncs settings through your browser account.

  • Request and response headers with URL and regular-expression filters, several active "pages" (profiles) at once, comments on headers.
  • Smaller than the others (7,000 Chrome users), but highly rated.

Listings named "ModHeader" that are not ModHeader

A Chrome Web Store search for "modheader" on 2026-11-20 returned 10 listings with ModHeader in the name. None of them is at the original ModHeader address (extension ID idgpnmonknjnojddfkpgkljpfnnfcklj, which still shows no listing). They had between 35 and 30,000 users each, and all were last updated between July and November 2026, after the original was removed. One more is on Firefox Add-ons.

We did not check who publishes them, what their code does, or whether they import ModHeader files. A familiar name tells you nothing about who wrote the code. If you are considering one, run the checks for any header extension first: read its permissions, look for public source, and watch its network requests.

Chrome DevTools response-header overrides

Best for: trying one response header change quickly, with nothing to install.

  • Since Chrome 113, the Network panel can override response headers, saved to a local folder you choose (Chrome's documentation).
  • In our test in Chrome 159, overrides applied only in the tab whose DevTools was open, stopped when DevTools closed, and did not reach CORS preflight responses (the OPTIONS check a browser sends before some cross-site requests). DevTools overrides cannot change request headers.

How to choose

  1. Do you only need headers? If you also need mocks, body changes or an API client, choose Requestly or Tweak. Requestly if you need team features; Tweak if you want low prices and no account.
  2. Must it come from a store today? HeaderDial is not in a store yet, and on a managed work machine you may only be allowed store installs. Then choose a store-listed tool now: Header Editor, Requestly, Tweak or FlexHeader. You can switch later.
  3. Do you need Firefox? Header Editor, Simple Modify Headers, Modify Header Value, Tweak and FlexHeader are on Firefox Add-ons. Requestly offers a download from its own site. HeaderDial is in review there.
  4. How much do you want to trust? A header editor can see or change every request it is allowed to touch. Prefer public source, a short permission list and no account. Check what the extension's code can see: rules handed to the browser (declarativeNetRequest), or every request (webRequest). How to check.
  5. Do you have ModHeader profiles to bring? HeaderDial, Requestly and FlexHeader read ModHeader's export file. Header Editor offers a converter. If you have no export, see the next section.

Moving from ModHeader

  1. Keep your profiles before you remove ModHeader. Removing an extension deletes its data. If you never exported, recover the profiles from ModHeader's data folder. The page runs in your browser and uploads nothing, and the file it gives you works in any tool above that imports ModHeader files.
  2. Import them. For HeaderDial, see import your ModHeader profiles, which lists what carries over. For other tools, follow their own import guide.
  3. Remove ModHeader and replace secrets. If your profiles held tokens or API keys, issue new ones. Why.
