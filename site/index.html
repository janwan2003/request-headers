Change HTTP request and response headers, and nothing else.

HeaderDial is a small, open-source extension for Chrome, Edge and Firefox. Add an Authorization token for staging, set X-Forwarded-For, strip a Cookie, or add CORS headers while you develop. No account, no analytics, no network requests.

Get HeaderDialRead the sourceFree. MIT licence.

Request and response headers

Set, append or remove any header on requests, and on responses the page receives. Page loads, fetch/XHR, images, scripts and WebSockets.

Profiles

One profile per environment or teammate, each with a colour. Run several at once; the leftmost wins a conflict. One switch, or Alt+Shift+D, pauses everything.

Filters

Limit a profile to domains, URL patterns or regexes, exclude paths like /healthz, pick request types, or bind it to a single tab.

Headers that switch themselves off

Give a header 15 minutes, an hour or a day. Short-lived tokens stop being sent when they expire, and you see the time left.

URL redirects

Send requests for one URL to another: a production script to localhost, an API version to the next one. Text replacement or regex with groups, on page loads and fetch. How.

Cookies by name

Send one extra cookie with every matching request while keeping the real ones, or store a cookie in the browser as if the server had set it. No cookies permission needed. How.

Copy as curl

Turn a profile into a ready-to-paste curl command for the page you are on, with its headers and cookies, to reproduce a request in the terminal or a bug report.

Import from ModHeader, share without a server

Open the JSON your ModHeader profiles were exported to: headers, cookies, URL filters and URL replacements come across. No export? HeaderDial can recover profiles from a disabled ModHeader's data folder. Share a profile as a link; the profile lives after the #, so nothing is uploaded.

Why another header extension?

In July 2026 Google and Microsoft removed the best-known header extension from their stores after researchers found a dormant browsing-history collector inside its signed build (The Hacker News). A tool that sees every request you make should be one you can check. HeaderDial is built for that:

  • The code is public and has no build step: the files in the extension are the files in the repository.
  • No network requests, no analytics, no remote code. Your profiles stay in the browser's local extension storage.
  • Few permissions. It uses the browser's declarativeNetRequest API, so it never reads the content of your traffic: it hands the browser a list of rules, and the browser applies them. Site access is optional and asked for when you need it, for all sites or just the one you are on.

Install

Firefox

HeaderDial on Firefox Add-ons (Firefox 128 or later). It was submitted on 2026-11-20 and becomes installable there once Mozilla's review is done.

Chrome and Edge

HeaderDial is on its way to the Chrome Web Store and Edge Add-ons. Until it is listed, install it from the release zip in under a minute:

  1. Download headerdial.zip and unzip it into a folder you will keep.
  2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin HeaderDial to the toolbar, click it, add a header, and click Allow on all sites (or allow only the site you are on).

Want to know when the store version is live? Watch the repository for releases.
